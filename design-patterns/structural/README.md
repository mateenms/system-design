# Structural Design Patterns

Patterns that compose classes and objects into larger structures.

| Pattern | Intent |
|---------|--------|
| Adapter | Make incompatible interfaces work together |
| Bridge | Separate an abstraction from its implementation |
| Composite | Treat single objects and trees of objects uniformly |
| Decorator | Add behaviour to an object dynamically |
| Facade | Provide a simple interface to a complex subsystem |
| Flyweight | Share common state to support many fine-grained objects |
| Proxy | Control access to another object |
