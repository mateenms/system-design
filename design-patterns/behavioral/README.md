# Behavioral Design Patterns

Patterns that define how objects interact and distribute responsibility.

| Pattern | Intent |
|---------|--------|
| Strategy | Swap interchangeable algorithms at runtime |
| Observer | Notify dependents automatically when state changes |
| Command | Encapsulate a request as an object |
| State | Change behaviour when internal state changes |
| Template Method | Fix an algorithm's skeleton, let subclasses fill in steps |
| Chain of Responsibility | Pass a request along a chain of handlers |
| Iterator | Traverse a collection without exposing its structure |
| Mediator | Centralise communication between objects |
| Memento | Capture and restore an object's state |
| Visitor | Add operations to classes without modifying them |
| Interpreter | Define a grammar and interpret sentences in it |
